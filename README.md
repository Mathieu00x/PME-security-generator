# PME-security-generator
AI-powered security policy generator for small medium business

Objectif
- Permettre a une PME de generer en moins de 10 minutes des politiques de cybersecurite professionnelles, personnalisees et pretes a etre utilisees

Fonctionnalités du MVP
1. Authentification
   - Inscription
   - Connexion
   - Deconnexion
   - Reinitialisation du mot de passe
   - Verification de l'adresse courriel(opt)
     
2. Profil de l'entreprise
   - Nom de l'entreprise
   - Secteur d'activite
   - Nombre d'employes
   - Pays
   - Province/Etat
   - Telephone
   - Courriel
   - Site web(opt)

     Informations de securite
     - Travail a distance
     - Utilisation du cloud
     - Microsoft 365 / Google Workspace
     - MFA active ?
     - Sauvegardes ?
     - Responsable TI ?


  3. Generation de politiques
     - Password policy
     - Backup policy
     - Incident Response Plan
     - Acceptable use policy
     - Remote work policy

     Ensuite -> questionnaire specifique -> generate


  4. Historique

     Chaque politique generee est sauvegardee. L'utilisateur peut :
     - ouvrir
     - renommer
     - supprimer
     - telecharger


  5. Export PDF

     Un bouton -> Download PDF
     PDF doit avoir :
     - logo
     - titre
     - date
     - numero de version
     - table des matieres (opt)
     - mise en page professionnelles
    
  6. Score de securite et recommandations
     
     Apres avoir rempli le questionnaire :
     
      - Strengths
      - Weakness
      - Recommandations
